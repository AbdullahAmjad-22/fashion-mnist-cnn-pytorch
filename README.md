# Fashion-MNIST Classification Using PyTorch

## Overview
This project trains and compares two Convolutional
Neural Networks (CNNs) to classify clothing images
in the Fashion-MNIST dataset.

## Technologies
- Python
- PyTorch and torchvision
- Matplotlib

## Models and Results
| Model | Test accuracy |
|---|---:|
| Baseline CNN | 91.57% |
| Advanced CNN | 92.27% |

## Project Contents
- `fashion_mnist_cnn.ipynb` — training and evaluation notebook.

## How to Run
1. Open the notebook in Google Colab.
2. Select a runtime; use a GPU if needed and available.
3. Run the notebook cells in order.

## Notes
The reported accuracy values are from my experiments.
Results can vary if the training configuration changes.
